# 0.9.1 — First Strike

SoundSticks 5 for Home Assistant 的首个公开 Release。

## 本次发布

- 通过本地蓝牙 BLE 控制音量、灯光开关、六种灯效、亮度、颜色、速度、七段 EQ 和设备设置。
- Lovelace 卡片随集成安装和更新；界面管理资源模式下自动注册，可在仪表板中直接添加。
- 播放控制支持自动、指定媒体实体、仅蓝牙 BLE 三种模式；可读取对应媒体实体提供的歌名和歌手。
- 场景预设支持保存、应用和删除，也可通过 HA 动作用于自动化。
- 配备「5 的声腔」集成图标及深浅色版本。
- 蓝牙 BLE 连接失败时提供 App 占用、覆盖范围和代理状态的排查提示，明确区分蓝牙 BLE 控制与蓝牙音频播放。

## 安装

推荐通过 HACS 自定义仓库安装 `neqq3/soundsticks5-ha`，类别选择 **Integration / 集成**。安装后重启 HA，添加集成，再刷新浏览器并添加 SoundSticks 5 卡片。

手动安装可下载附件 `soundsticks5-0.9.1.zip`，将其中的 `custom_components/soundsticks5` 复制到 HA 的 `/config/custom_components/soundsticks5`。

- [第一次使用：集成与 Lovelace 卡片](https://github.com/neqq3/soundsticks5-ha/blob/v0.9.1/docs/getting-started.md)
- [播放源选择](https://github.com/neqq3/soundsticks5-ha/blob/v0.9.1/soundsticks5-card/PLAYBACK.md)

## 要求与边界

- 最低 HA 版本为 **2025.12.2**；集成自带图标需要 **2026.3+**。
- 需要支持连接的蓝牙 BLE 适配器或代理；仅转发广播的代理不够。
- 本集成负责蓝牙 BLE 控制，不传输音频，也不承诺通过蓝牙 BLE 唤醒深度待机的音箱。
- 歌名、歌手取决于实际播放源或音箱回传；蓝牙音频正在播放不保证蓝牙 BLE 一定回传曲目信息。
- 当前以一台普通版 SoundSticks 5 为验证基础，更多固件、地区和代理组合仍需验证。
- 使用 YAML 管理卡片资源时需要手动添加资源地址，见入门指南。

此前的 `1.x` 为开发过程中的版本编号；`0.9.1` 是首个公开 Release 的起点。已安装开发版的测试用户如未看到更新提示，可在 HACS 中重新下载并选择 `v0.9.1`。不需要为此删除集成或已有预设。

---

First public release of the unofficial SoundSticks 5 integration, with local Bluetooth BLE controls, a bundled Lovelace card, selectable playback sources, presets and integration icons.

Requires Home Assistant 2025.12.2 or later; local integration icons require 2026.3+. Bluetooth BLE control and Bluetooth audio playback are separate connections. Audio transport is outside this integration's scope. Track metadata depends on the selected playback entity or actual device reports.
